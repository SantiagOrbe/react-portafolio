# Portafolio de Santiago Orbe

Portafolio personal construido con React, React Router y Vite. La interfaz está
en español y se adapta a pantallas pequeñas y grandes.

## Desarrollo

```sh
npm install
npm run dev
```

## Comprobaciones

```sh
npm run lint
npm run build
```

## Estructura

- `src/components/`: páginas y componentes reutilizables.
- `src/data/trabajos.js`: contenido de los proyectos que se muestra en Inicio,
  Proyectos y las páginas de detalle.
- `src/layout/`: navegación y pie de página.
- `src/routes/`: configuración de React Router.
- `src/index.css` y `src/App.css`: tokens globales, componentes y diseño
  adaptable.

Los proyectos incluidos son conceptos ficticios para demostración. Sus enlaces
usan `example.com` y no representan repositorios ni demos publicados. Sustituye
los textos y enlaces de `src/data/trabajos.js` por información verificada antes
de publicar el portafolio.

El formulario de contacto es actualmente una maqueta visual: no almacena ni
envía datos.
